## Контракт calcInstallment

Доступний опис варіанта: «Місячний платіж для 3, 6 та 12 місяців із надбавкою
2% за кожні три місяці».

Наведені нижче рішення є явно прийнятими припущеннями, а не цитатами з методички:

- Надбавка проста, без капіталізації: 2%, 4%, 8% до початкової суми.
- Місячний платіж до округлення: `total × (1 + surcharge) / months`.
- Валютна одиниця умовна; результат має точність до копійок, тобто 2 знаки.
- Дозволено скінченні невід’ємні числа, зокрема нуль, `-0` та дробові значення
  з більш ніж двома знаками. Вхідна сума попередньо не округлюється.
- Остаточний платіж округлюється до копійок за правилом «половину вгору».
- Для відтворюваного округлення десятковий запис `number.toString()`
  перетворюється на точний раціональний дріб із `BigInt`. Підтримано також
  експоненційний запис. Це не відновлює точність, втрачену до виклику функції.
- Якщо округлений платіж у копійках перевищує `Number.MAX_SAFE_INTEGER`,
  обчислення відхиляється. Результат повертається як JavaScript `number`.
- При одночасно некоректних аргументах спочатку перевіряється сума.
- Різниця між сумою округлених платежів і повною вартістю не розподіляється
  на останній платіж: функція повертає лише один місячний платіж.

Строки та параметри надбавки ізольовано в `INSTALLMENT_MONTHS`,
`SURCHARGE_PERCENT_PER_PERIOD`, `SURCHARGE_PERIOD_MONTHS`. Правило округлення
локалізовано в розрахунку `roundedCents`; перетворення десяткової суми —
у `decimalFraction`.

| Приклад  | Очікуваний місячний платіж |
| -------- | -------------------------: |
| 1200, 3  |                        408 |
| 1200, 6  |                        208 |
| 1200, 12 |                        108 |
| 100, 6   |                      17.33 |
| 0.749, 3 |                       0.25 |
| 0.75, 3  |                       0.26 |
| 0.751, 3 |                       0.26 |

| Код InstallmentError     | Умова                                                        |
| ------------------------ | ------------------------------------------------------------ |
| INVALID_TOTAL            | Від’ємна, нескінченна або нечислова сума                     |
| UNSUPPORTED_MONTHS       | Строк не дорівнює числу 3, 6 або 12                          |
| INSTALLMENT_OUT_OF_RANGE | Округлений платіж у копійках поза безпечним цілим діапазоном |

Зміна кожного показника — 0 відсоткових пунктів. Покриття вже було повним,
тому новий виклик не охопив додаткових шляхів. Вимірювання показує виконання
коду, але не перевіряє правильність результату. Тест без твердження виявить
неочікуваний виняток, проте пропустить хибний числовий результат. Навіть 100%
покриття не доводить повноту специфікації, незалежність очікувань або якість
перевірок. Саме тому відсутні функції частини 1 не можна вважати перевіреними
на підставі 100% покриття наявних файлів.

Відтворення: `npm run experiment:installment`. Скрипт зберігає справжні журнали
й JSON-звіти трьох запусків, видаляє власний тимчасовий тест у `finally` та
повторно запускає покриття. Чужий однойменний файл не перезаписується.

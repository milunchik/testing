# Шаблон взаємного рецензування — не виконана рецензія

Статус: очікує реального Pull Request іншого студента. Наведені нижче
формулювання є шаблонами для заповнення після перегляду коду, а не висновками
про будь-яку наявну роботу. Коментарі не надсилалися.

Автор PR: [заповнити]. URL PR: [заповнити]. Переглянутий commit: [заповнити].

## Коментар 1 — відповідність бізнес правилам

Файл і рядок: [заповнити]. Правило специфікації: [точна цитата або посилання].
Фактичний фрагмент: [вставити]. Для входу [конкретні дані] очікується
[незалежне значення], а поточний код повертає [фактичне значення].
Пропозиція: [конкретне виправлення або обґрунтований позитивний висновок].

## Коментар 2 — межові умови та помилки

Файл і рядок: [заповнити]. Перевірені сусіди межі: [межа − 1, межа, межа + 1].
Наявний результат: [підтверджений запуском або читанням коду].
Пропозиція: [конкретний тест, аргументи, очікування чи покращення валідації].

## Коментар 3 — якість перевірок і покриття

Файл і рядок: [заповнити]. Наявне твердження: [вставити].
Виявлений ризик: [наприклад, повторення формули реалізації або відсутність
перевірки коду помилки, лише якщо це справді є в коді].
Пропозиція: [конкретний незалежний еталон чи перевірка]. Фактичні дані
покриття та неперевірений шлях: [заповнити за звітом].

Перед поданням кожного коментаря необхідно звірити його з реальним кодом
і вилучити всі незаповнені поля. Підсумковий висновок про PR формулюється
лише після такої перевірки.

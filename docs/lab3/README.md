# Лабораторна робота №3 — TDD, варіант 12

Методичку `Лабораторна 3_Практикум TDD.docx` прочитано повністю. Реалізація
зберігає лабораторні №1 і №2 та додає два незалежні чисті модулі.

## API та політика

`calcParkingFee(minutes, options?)` приймає невід'ємну цілу кількість хвилин.
0–15 хв — безкоштовно, 16–60 — 30 грн, кожна наступна розпочата година — 20 грн,
максимум — 200 грн; потім нічний множник 0,5 і вихідний множник 0,8.
Округлення виконується наприкінці. Як у методичці, це один розрахунок із межею
200 грн, без додатково вигаданої багатодобової тарифікації.

`calcInsuranceCost({ vehicleAge, driverExperience, accidentFreeDiscountPercent? })`
повертає суму в гривнях. Вік — невід'ємне безпечне ціле число років; стаж —
скінченне невід'ємне число років, зокрема дробове. Знижка — скінченний
невід'ємний відсоток, за замовчуванням 0. Значення понад 30 обмежуються.

**Припущення автора, а не числа з методички:** базова ціна 3000 грн для віку
0–3 роки, 4000 грн для 4–10, 5000 грн для 11+; надбавка 25% за стажу <3.
Методичка задає лише залежність від віку, межу стажу 3 роки та максимум знижки
30%. Вхідний відсоток означає вже встановлене право на знижку за безаварійність;
правила накопичення такого права не задані й не моделюються.

Надбавка застосовується до бази, знижка — до збільшеної суми. Остаточні копійки
обчислюються через `bigint` із десяткового запису відсотка, із округленням
половини вгору. Це усуває виявлену в додатковому циклі TDD похибку JavaScript:
0,0075% від 3000 грн дає 2999,775 грн, результат має бути 2999,78.

Коди `RangeError`: `INVALID_VEHICLE_AGE`, `INVALID_DRIVER_EXPERIENCE`,
`INVALID_ACCIDENT_FREE_DISCOUNT`. Паркування: `Error('INVALID_DURATION')`.

## Відтворення та докази

```bash
npm test -- tests/parking.test.ts
npm test -- tests/insurance.test.ts
npm run verify
npm run evidence:lab3
git log --oneline
git status
```

Поріг гілок страхування ≥90% перевіряється і Vitest, і незалежним скриптом
за фактичними лічильниками `coverage-final.json`. Пороги попередніх робіт
збережено. Журнали, JSON-метадані та знімки кожного етапу:
`report/lab3/evidence`; усі PNG отримано автоматично через Playwright у
`report/lab3/screenshots`. Переглядач журналів чітко позначений як execution-log
viewer, а його текст звіряється з оригінальними stdout/stderr. Це не імітація
термінала. HTML-покриття знімається безпосередньо у браузері.

Вісім циклів паркування та вісім циклів страхування мають окремі коміти
`red:`, `green:`, `refactor:`. Перший Red кожного модуля — відсутній імпорт,
як передбачено методичкою. Тести округлення паркування перевіряють окрему
функцію: фіксовані тарифи самі по собі завжди дають цілі суми, тому наведені
в методичці перевірки 12 і 28 проходять ще до додавання округлення.

Незалежне рецензування очікує посилання на реальну роботу однокурсника;
незаповнений шаблон наведено у звіті. Власна історія не видається за рецензію.
